# Speech-to-text translation

**Objective:** recognize one spoken utterance and display translations in multiple target languages. This solves the first reception step: understand and read a caller request. Run `python demos/m3/07-azure-speech-translation/speech_to_text_translation.py`; configure `AZURE_SPEECH_KEY` and `AZURE_SPEECH_REGION`. It uses `SpeechTranslationConfig`, sets one source and multiple target codes, then reads `result.text` and `result.translations`. Expected: source transcript and each target translation. Handle `NoMatch` separately from `Canceled`; check microphone privacy, source locale, region, quota and key. Do not use personal audio. Exam: recognize that speech translation combines ASR and translation; translated text is not generated speech. See the [module guide](../README.md) and [Microsoft Learn](https://learn.microsoft.com/azure/ai-services/speech-service/how-to-translate-speech?pivots=programming-language-python).
