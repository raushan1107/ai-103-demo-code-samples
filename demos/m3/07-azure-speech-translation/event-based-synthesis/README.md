# Event-based speech synthesis

**Objective:** use the Speech Translation recognizer's `synthesizing` event to capture spoken output for one target. Run `python demos/m3/07-azure-speech-translation/event_based_synthesis.py`; set Speech key/region and select a target plus a compatible neural voice. The callback receives `event.result.audio` chunks and saves them under `audio/`. Expected: transcript, translated text, and an output audio file. The event workflow supports one target translation only; use manual synthesis for several. Check voice locale, audio format, microphone and cancellation details. Use synthetic speech. Exam: understand event-based callbacks and distinguish integrated single-language synthesis from separate synthesis calls.
