# Manual multi-language synthesis

**Objective:** translate one microphone turn to multiple languages, then synthesize each translation independently. Run `python demos/m3/07-azure-speech-translation/manual_synthesis.py`; configure Speech key and region, source, targets and compatible neural voices. The recognizer's translations dictionary feeds one `SpeechSynthesizer` per target; output WAV files are separate. Expected: target text and a WAV path for every successful target. Diagnose speech translation and TTS independently. No input audio is retained by this script, but synthesized examples remain in the local `audio/` directory. Exam: manual synthesis enables multiple voices/languages and lets code control each output.
