# Foundry model application

The M1 Responses API wrapper is `app/services/foundry_model.py`; `app/agents/tool_agent.py` adds function calling. The Text Assistant lets you compare a basic grounded response (context inserted, no tool calls) with local function calling and Foundry Agent Service. Configure the OpenAI-compatible endpoint, key and deployment for the M1 paths. See [GlobalCare README](../README.md).
